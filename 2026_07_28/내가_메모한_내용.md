### Claude Code 안에서 gh CLI로 GitHub 연동하는 전체 흐름을 순서대로 정리

Claude Code는 터미널 명령을 대신 실행해주는 도구이기 때문에, 아래 단계들을 "그대로 Claude Code에게 시키면" 됩니다.
1단계: gh CLI 설치 확인
- gh --version 확인해줘. 없으면 설치해줘.

2단계: GitHub 계정 인증 (gh auth login)
- gh auth login 실행해줘
- 이 과정은 **인터랙티브(대화형)**입니다. 터미널이 안내하는 대로:
  - GitHub.com 선택
  - HTTPS 선택 (권장)
  - 브라우저로 인증할지 물어보면 Login with a web browser 선택
  - 코드가 표시되면 그 코드를 복사해서 브라우저에서 GitHub 로그인 후 붙여넣기
- 이 부분은 브라우저 인증이 필요하므로 Claude Code가 자동으로 완료 못 시킬 수 있습니다. 코드가 뜨면 직접 브라우저에서 인증해주세요.
- 인증확인
  - gh auth status

3단계: 프로젝트 폴더에서 git 초기화
- 이미 git 저장소가 아니라면: 현재 폴더에서 git init 해줘. 그리고 .gitignore 만들어줘 

4단계: 첫 커밋
- git add . 하고 git commit -m "Initial commit" 해줘

5단계: GitHub에 새 저장소 생성 + 연결 (gh repo create)
- 이게 gh CLI의 핵심 기능입니다. 한 번에 로컬 저장소를 GitHub에 새 repo로 만들고 연결까지 해줍니다
- gh repo create [저장소이름] --private --source=. --remote=origin --push 실행해줘
- 옵션 설명:
  - --public : 공개 저장소 (비공개는 --private), 우리는 --private으로 한다.
  - --source=. : 현재 폴더를 소스로 사용
  - --remote=origin : origin이라는 이름으로 remote 등록
  - --push : 생성과 동시에 바로 push까지 진행

6단계: 확인
- gh repo view --web
- 브라우저로 방금 만든 저장소가 열립니다.

참고: 이후 작업 흐름
한 번 연동되면, 이후에는 이렇게 짧게 요청해도 됩니다
- 변경사항 커밋하고 push 해줘
- Claude Code가 알아서 git add, git commit -m "적절한 메시지", git push를 실행해줍니다.

주의할 점:
- 2단계(gh auth login)의 브라우저 인증 코드 입력은 보안상 사람이 직접 해야 하는 부분이라, Claude Code가 완전 자동으로는 못 넘어갈 수 있어요.
- private repo로 하고 싶으면 --public 대신 --private로 바꿔주세요.
