### 학습 목표

1. **워크플로우**와 **에이전트**의 **차이**를 설명한다
2. **n8n** **환경**을 스스로 구축한다
3. **트리거**-**노드**-**실행**의 **기본** 사이클을 손으로 익힌다
4. 실행 로그로 문제를 진단한다

### 에이젼트의 4대 구성 요소

1. 모델 (Brain) : 판단과 생성을 담당하는 LLM
2. 도구 (Hands) : 검색, API 호출, 파일 읽기 등 모델이 호출할 수 있는 기능
3. 메모리 (Memory) : 대화 이력, 작업 상태, 장기 지식
4. 루프 (Loop) : 생각 → 행동 → 관찰을 반복하는 제어 구조 (ReAct)

n8n은 이 중 루프와 도구 연결을 마우스로 그리게 해주는 도구입니다. 코드 없이 아키텍처를 익힐 수 있어서 교육적으로 최고의 출발점이고, 동시에 실무에서도 그대로 쓰이는 프로덕션 도구입니다.

### 그럼 n8n의 각 노드는 이 4가지 중 무엇인가요?
- **모델** : LLM 노드, AI Agent 노드 (OpenAI/Claude Chat Model)
- **도구** : HTTP Request 노드, Gmail/Slack 등 액션 노드, 그리고 AI Agent에 붙이는 Tool 노드
- **메모리** : Memory 노드 (Window Buffer Memory 등), 또는 외부 DB
- **루프** : AI Agent 노드가 내부적으로 돌리는 ReAct 루프, 또는 워크플로우 레벨의 Loop/IF 노드

*** n8n이 뭐예요?
- 오픈소스 워크플로우 자동화 도구. 노드(블록)를 선으로 연결해 자동화를 만듭니다.
- 경쟁 서비스 : Zapier, Make. n8n의 강점은 셀프호스팅 가능(데이터 주권!)과 AI 노드 생태계입니다.

### 참고로 self hosting에 대해서 알아보자.

### 셀프 호스팅이란?

"셀프 호스팅(self-hosting)"은 어떤 서비스나 소프트웨어를 남의 서버(클라우드 업체)에 
맡기지 않고, 내가 직접 관리하는 컴퓨터/서버에 설치해서 운영하는 방식을 말합니다.

### 클라우드 vs 셀프 호스팅

| 구분 | 클라우드(SaaS) | 셀프 호스팅 |
|---|---|---|
| 서버 위치 | 업체가 관리 (예: n8n.cloud) | 내 컴퓨터/서버 (로컬 PC, VPS 등) |
| 설치/관리 | 필요 없음 | 직접 설치, 업데이트, 백업 담당 |
| 비용 | 구독료 (월/년 단위) | 서버 비용만 (또는 무료) |
| 데이터 | 업체 서버에 저장 | 내 서버에만 저장 (프라이버시↑) |
| 커스터마이징 | 제한적 | 자유롭게 설정 가능 |

### 장단점

**장점**
- 데이터를 외부에 안 보내도 됨
- 사용량 제한 없이 무료로 쓸 수 있음
- 자유로운 커스터마이징 가능

**단점**
- 서버 관리 지식 필요 (Docker, 네트워크, 보안 패치 등)
- 컴퓨터를 꺼두면 워크플로우도 멈춤
- 문제 생기면 스스로 디버깅해야 함
